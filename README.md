# 🔊 音量控制工具 (Volume Control)

一个功能强大的Windows系统音量控制工具，能够为每个应用独立控制音量，支持自动监听新打开的应用。

## ✨ 功能特性

- 🎵 **应用独立音量控制** - 为系统中的每个应用单独调节音量
- 👀 **实时进程监听** - 自动检测新打开的有声音输出的应用
- 🎚️ **精确音量调节** - 0-100% 的精确音量控制
- 🔇 **快速静音** - 一键为应用静音
- ⚙️ **自动化功能** - 启用后新应用自动降音量到指定值
- 🧾 **黑白名单过滤** - 支持黑名单和白名单管理自动控制应用
- 💾 **音量预设** - 保存、加载、删除预设配置
- 🎹 **全局热键** - Ctrl+Shift+Up/Down 调整应用音量，Ctrl+Shift+M 切换静音
- 🖥️ **系统托盘支持** - 最小化到托盘，右键菜单快速恢复/退出
- 🌙 **深色主题** - 可选明亮或深色界面主题
- 💾 **配置保存** - 设置会自动保存
- 🎨 **美观界面** - 现代化的PyQt5用户界面

## 📋 系统要求

- Windows 7 或更高版本
- Python 3.7+ (如果从源代码运行)
- .NET Framework (某些功能需要)

## 🚀 快速开始

### 方法一：直接运行EXE（推荐）

1. 下载 `dist/VolumeControl.exe`
2. 双击运行
3. 完成！无需任何依赖

### 方法二：从源代码运行

#### 1. 安装依赖
```bash
pip install -r requirements.txt
```

#### 2. 运行应用
```bash
python main.py
```

## 📦 打包成EXE

如果你修改了源代码，可以重新打包成EXE：

```bash
python build.py
```

生成的EXE文件将在 `dist/VolumeControl.exe`

## 📖 使用说明

### 主界面

1. **🎵 应用音量** 标签页
   - 显示所有当前运行的有音频输出的应用
   - 使用滑块调节每个应用的音量
   - 点击"重置"使用默认音量
   - 点击"🔇 静音"快速静音应用

2. **⚙️ 设置** 标签页
   - **默认应用音量** - 新打开的应用或点击重置时使用的音量
   - **启用自动音量控制** - 启用后，新打开有音频的应用会自动降到指定音量

### 热键（计划功能）
- `Ctrl+Shift+Up` - 提高应用音量
- `Ctrl+Shift+Down` - 降低应用音量
- `Ctrl+Shift+M` - 快速静音当前应用

## 🔧 配置文件

配置文件位置：`~/.volume_control/config.json`

```json
{
  "default_volume": 50,
  "auto_control_enabled": true,
  "monitored_apps": {},
  "theme": "light"
}
```

## 🐛 故障排除

### 应用列表为空
- 确保已有应用正在播放声音
- 尝试打开浏览器或音乐播放器
- 检查系统音量是否为0

### 无法调节某个应用的音量
- 该应用可能不支持独立音量控制
- 尝试重启应用
- 检查应用是否使用了特殊的音频输出方式

### 获取系统权限错误
- 尝试以管理员身份运行程序
- 右键点击EXE，选择"以管理员身份运行"
