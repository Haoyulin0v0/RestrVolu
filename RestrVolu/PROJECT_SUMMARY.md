## 🚀 快速开始方式

### 方式一：直接启动（推荐）
```bash
run.bat
# 或
python main.py
```

### 方式二：构建EXE
```bash
build.bat
# 然后双击 dist\VolumeControl.exe
```

### 方式三：虚拟环境（开发者）
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
