﻿# 音量控制工具 - 快速开始指南

## 🚀 30秒快速开始

### 对于普通用户（使用EXE）

1. **双击运行** `VolumeControl.exe`
2. **打开任何有声音的应用**（如浏览器、音乐播放器）
3. **在"🎵 应用音量"标签页中调节音量**
4. **设置默认音量**（在"⚙️ 设置"标签页中）

完成！就是这么简单。

### 对于开发者（从源代码运行）

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行应用
python main.py
```

### 三个简单操作

| 操作 | 说明 |
|------|------|
| **滑动音量条** | 实时调节应用音量（0-100%） |
| **点击"重置"** | 恢复到默认音量 |
| **点击"🔇 静音"** | 快速让应用无声 |

## ⚙️ 设置详解

### 默认应用音量
- 新打开的应用会使用这个音量
- 也是"重置"按钮会恢复的音量
- 范围：0-100%

### 启用自动音量控制
- **启用**：新打开的应用自动降到默认音量
- **禁用**：应用保持原有音量

## ❓ 常见问题

### Q: 为什么看不到任何应用？
**A:** 你需要打开一个有声音输出的应用，如：
- Chrome / Edge / Firefox（播放YouTube视频）
- Spotify / NetEase Music（音乐播放器）
- Windows Media Player
- 任何其他音频应用

### Q: 为什么某个应用的音量改不了？
**A:** 原因可能是：
1. 应用不支持独立音量控制
2. 应用已关闭
3. 需要以管理员身份运行

**解决方法：**
- 右键点击EXE → "以管理员身份运行"

### Q: 配置文件在哪里？
**A:** 在你的用户目录：
- Windows: `C:\Users\你的用户名\.volume_control\config.json`
- 应用会自动创建和保存

### Q: 关闭应用后设置还在吗？
**A:** 会的！所有设置都会自动保存：
- 默认音量
- 自动控制开关
- 应用配置
